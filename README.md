#  ReadQuotely

Kullanıcıların okudukları kitapları ekleyebildiği, bu kitaplara etiketli alıntılar ve kişisel notlar iliştirebildiği minimalist bir kitap ve alıntı yönetim platformu.

##  Kullanılan Teknolojiler
* **Backend:** Python, Flask
* **Veritabanı:** SQLite, SQLAlchemy ORM
* **Frontend:** HTML, Vanilla JS, Tailwind CSS

##  Kurulum ve Çalıştırma
1. Projeyi bilgisayarınıza indirin.
2. Sanal ortamı aktif edin: `.\venv\Scripts\activate`
3. Gerekli kütüphaneleri kurun: `pip install -r requirements.txt`
4. Uygulamayı başlatın: `python app.py`
